# База отдыха «Графит»

Учебный проект на ASP.NET Core MVC (.NET 10).

## Сейчас сделано

- Основные страницы: главная, о базе, услуги, бронирование, отзывы, контакты
- Регистрация и вход (ASP.NET Identity + SQLite)
- Личный кабинет (профиль)
- Графитовая временная вёрстка

## Запуск

```bash
dotnet run
```

Откройте адрес из консоли (обычно `https://localhost:7xxx`).

## Тестовый аккаунт

Зарегистрируйте нового пользователя через сайт — подтверждение email отключено.
